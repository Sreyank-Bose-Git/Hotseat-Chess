# Contributing

Thanks for your interest in improving Hotseat Chess!

## How to Contribute
1. Fork the repository.
2. Create a focused branch for your change.
3. Keep changes minimal and well-scoped.
4. Test your change in a browser by playing a short game.
5. Open a pull request with a clear summary.

## Development Notes
- This project is a static web app (HTML/CSS/JS only).
- No build tooling is required.
- Keep UI changes accessible and responsive.
- Avoid introducing dependencies unless absolutely necessary.

## Pull Request Checklist
- [ ] Change is scoped to one issue
- [ ] Updated docs when behavior/UI changed
- [ ] Manually tested in browser
- [ ] No secrets or credentials included
